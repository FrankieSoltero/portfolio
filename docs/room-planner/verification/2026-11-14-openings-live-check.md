## Defects found

1. **C5: after you select a door on the plan by pointer, the arrow keys go to whatever control still has focus.**
   Pressing or dragging a plan handle (`button.room-opening`) does not focus it: its `pointerdown` handler prevents the default. If a sidebar radio group still has focus, ArrowRight changes that radio instead of sliding the door. Delete still removes the door.
   Reproduce:
   1. `npm run build && npx next start -p 3210`, open `http://localhost:3210/room-planner` with the key removed.
   2. `Edit room` → `Add door` → `Place the door on wall 1` (offset 56, hinge `start`).
   3. Click the `Door on wall 1` row, then click `End of wall`. Stored hinge `end`; focus is now on the Hinge radio.
   4. Click (or drag) the `Door on wall 1` handle on the plan. `document.activeElement` is still the radio (`value=end`).
   5. Press ArrowRight. Stored offset stays 56 and stored hinge becomes **`start`**: the key press edited the hinge, not the door's position.

   The same focus behaviour exists for furniture pieces on the plan (clicking the bed with a units radio focused leaves the radio focused), so the cause predates this slice; the openings inherit it. With the handle focused (Tab or `focus()`), ArrowRight slides the door (56 → 59 for three presses) and Delete removes it.

2. **X1: in furnish mode the door's leaf and swing arc are hidden under furniture that blocks it.**
   Reproduce:
   1. Fresh storage. `Edit room` → `Add door` → `Place the door on wall 1` → `Done`.
   2. Click `Swap` to make the plan the main view (the inset shows the same).
   3. The top wall shows the door's gap (x 626.76 to 741.24 at 1440×900), but no leaf or arc is visible. `.plan-door-leaf` and `.plan-door-arc` exist, but the bed's `.plan-item` (`z-index: 2`, opaque hatched background) is painted on top and covers the whole swing area.

   This is the case where the arc matters most: the bed reads `Blocks a door`, yet the plan does not show what it blocks. In room mode the furniture is faded and the arc is visible (C1 screenshot).
