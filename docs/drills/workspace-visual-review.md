# Workspace visual review: 2026-11-23

How the drill page `/drills/like-button`, with the workspace skin
(`app/drills/workspace-theme.css`), compares with the mockup the owner approved on
2026-11-22 ("Drill page with the in-browser runner", kept in the Drillbox repository at
`.soltero/lean-sdd/2026-11-22-workspace-ui/mockup-drill-page.html`), region by region. It is
written from two screenshots taken by `e2e/drills-theme.spec.ts` in Chromium against a
production build, and from the computed styles that spec checks in Chromium, Firefox and
WebKit:

- 1280 × 900, full page, like-button starter, fresh storage, after `RUN CHECKS`
  (`1 OF 4 PASSING`): `test-results/drill-1280.png`.
- 390 × 844, full page, like-button starter, before any checks run:
  `test-results/drill-390.png`.

The mockup was screenshotted at 1280 wide (full page) for the comparison. "Differences"
lists everything that looks different from the mockup, and why where the reason is known.
The workspace region (toolbar to checks) carries the Drillbox demo's 8-bit theme value for
value; the page around it (header, title, the pull request, hints, the fix, links, footer)
was built by earlier tasks and is described as it is, not restyled here, except that Task 12
widened drill pages to the mockup's column (`max-width: 1160px`, 24 px side padding; the
`/drills` index keeps its 704 px column) with prose kept to 760 px. The rows for the page
header, title, the pull request, toolbar, editor, live preview, checks, links and footer, and
the narrow layout are written from the Task 12 screenshots. The verdict on the look is the
owner's.

How wide the mockup's column is, measured in Chromium at 1280 wide: the mockup sets
`max-width: 1160px; padding: 0 24px` on its `main` without `box-sizing: border-box`, so the
1160 px is its content width; its workspace row (editor plus preview) spans x 60 to x 1220,
1160 px, as do its toolbar and checks panel. This page sets the same `max-width: 1160px` with
24 px padding on a `box-sizing: border-box` column, so its content is 1112 px, x 84 to
x 1196: 48 px narrower than the mockup's, 24 px further in on each side. (An earlier version
of this file gave the mockup's row as 1112 px; that was wrong.)
